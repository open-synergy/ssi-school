=========================
School Student Withdrawal
=========================

Records a student's permanent exit from the school under one umbrella
document covering three reasons: Drop Out/Expelled, Resignation, and
No News/Whereabouts Unknown. The withdrawal reason determines the
target student state on completion (Resignation -> Resigned; Drop Out
and No News -> Dropped), and, when the student has an active
enrollment, marks that enrollment's academic year result as Drop Out.


Installation
============

To install this module, you need to:

1.  Clone the branch 14.0 of the repository https://github.com/open-synergy/ssi-school
2.  Add the path to this repository in your configuration (addons-path)
3.  Update the module list (Must be on developer mode)
4.  Go to menu *Apps -> Apps -> Main Apps*
5.  Search For *School Student Withdrawal*
6.  Install the module
