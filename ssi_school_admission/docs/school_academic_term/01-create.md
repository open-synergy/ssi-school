# Create School Academic Term

> **Module:** ssi_school_admission\
> **Extends:** ssi_school — model `school_academic_term`, aksi `01-create`

## Additional Fields

When this module is installed, the **Enrollment** tab gains one additional field:

- **Open for Admission**: Check this box to make this academic term available for
  selection in the School Admission wizard. Unchecked by default. Optional.
